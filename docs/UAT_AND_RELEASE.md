# UAT and Release Method

## UAT sequence

1. Define the business process and expected outcome.
2. Prepare test cases with clear expected results.
3. Assign testers representing actual roles.
4. Send a UAT invitation email.
5. Record pass, fail or blocked results.
6. Assign defects and required corrections.
7. Retest failed items.
8. Obtain process-owner and QA sign-off.
9. Create the approved release version.
10. Install or activate the version in production.
11. Send the go-live email.
12. Monitor early use and retain the evidence package.

## Minimum release evidence

- approved requirements;
- technical test results;
- UAT test cases and results;
- defect and retest records;
- process-owner sign-off;
- QA approval;
- version checksum;
- deployment record;
- rollback version;
- go-live communication.

## Suggested email sequence

- Review assignment
- Evidence required
- Corrective action required
- Reminder before due date
- Overdue escalation
- UAT invitation
- UAT defect notification
- UAT completion and sign-off request
- Go-live notice
- Closure notice
