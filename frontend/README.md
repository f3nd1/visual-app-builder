# Future Frontend

The current visual reference is in `prototype/`.

Do not rebuild the complete prototype as the first production task.

After the definition model and shared runtime work, the production Studio may use React and TypeScript for:

- page component drag and drop;
- relationship diagrams;
- workflow state and transition editing;
- automation nodes and edges;
- zoom, pan, selection and property panels;
- undo and redo;
- definition comparison;
- responsive preview.

The runtime used by ordinary staff should remain lighter than the design Studio.
