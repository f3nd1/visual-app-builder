# Prototype

`visual_app_builder_prototype.html` is a standalone interactive concept demonstration.

It is not production code and is not connected to ERPNext.

Use it to discuss:

- user journeys;
- workspaces;
- page-building interaction;
- relationship, workflow and automation diagrams;
- translation and permissions;
- testing, generated files and publication.

Production implementation should preserve the agreed behaviour while using a maintainable Frappe app structure.
