# Document Control Manager Requirements

## Purpose

Control policies, procedures, forms and templates from drafting through approval, issue, acknowledgement, review and obsolescence.

## Journey

```text
Draft
-> Department Review
-> QA Review
-> Approval
-> Controlled Issue
-> Distribution and Acknowledgement
-> Periodic Review
-> Revision or Confirmation
-> Obsolete and Archive
```

## Main records

- Controlled Document
- Document Version
- Review Comment
- Approval Record
- Distribution Record
- Acknowledgement
- Periodic Review
- Obsolete Copy Record

## Main features

- document code and owner;
- version comparison;
- controlled effective date;
- required reviewer and approver;
- acknowledgement tracking;
- review reminders;
- obsolete-copy marking;
- immutable issued versions;
- print or PDF control information;
- audit trail.

## Required emails

- review request;
- changes required;
- approval request;
- document issued;
- acknowledgement required;
- review due reminder;
- obsolete-document notice.
