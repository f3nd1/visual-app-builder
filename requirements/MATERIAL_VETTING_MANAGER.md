# Learning Material Vetting Manager Requirements

## Purpose

Manage academic learning material submission, vetting, correction, approval, release and later review.

## Journey

```text
Material Submitted
-> Completeness Check
-> Academic Vetting
-> Correction Required or Recommended
-> Resubmission
-> Re-vetting
-> Approval
-> Release to Course Team or LMS
-> Periodic Review
```

## Main records

- Material Submission
- Material File Version
- Vetting Checklist
- Vetting Comment
- Correction Request
- Approval Record
- Release Record
- Periodic Review

## Vetting areas

- learning outcome alignment;
- academic accuracy;
- currency and relevance;
- copyright and source attribution;
- assessment alignment;
- language and readability;
- accessibility;
- institutional formatting;
- answer-key or facilitator-guide completeness;
- inappropriate or sensitive content.

## Main features

- file and version tracking;
- side-by-side comments;
- score and decision;
- mandatory correction tracking;
- re-vetting;
- approval history;
- course and module links;
- release notification;
- review due date.

## Required emails

- vetting assignment;
- correction required;
- resubmission received;
- approval and release;
- periodic review due.
